# PAYOO — Smart MFS Interface

PAYOO is a mobile financial services (MFS) interface that simulates a digital banking experience. Users can manage their account balance, add money, cash out, transfer funds, earn bonuses, pay bills, and review their transaction history through an interactive dashboard.

## ✨ Features

- **Login Interface:** Access the application using username and password.
- **Home Dashboard:** View the available balance and access financial services.
- **Add Money:** Deposit money into the account.
- **Cash Out:** Withdraw money with PIN verification.
- **Send Money:** Transfer funds to other users.
- **Pay Bill:** Manage bill payment transactions.
- **Bonus Rewards:** Add promotional bonuses to the account.
- **Transaction History:** Review recorded financial activities.
- **PIN Verification:** Validate the PIN before performing supported transactions.
- **Responsive UI:** Navigate the interface across desktop and mobile devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- DaisyUI
- Font Awesome

## 📚 Key JavaScript Concepts

- **DOM Manipulation:** Update account balances, transaction records, and interface elements dynamically.
- **Event Handling:** Handle form submissions, button clicks, and financial service interactions.
- **Form Validation:** Validate user inputs before processing transactions.
- **Conditional Logic:** Apply transaction rules and verify PINs.
- **Array Methods:** Manage and display transaction records.
- **Dynamic Rendering:** Update the dashboard based on user actions.

## 🎯 Project Goal

The goal of this project is to practice JavaScript fundamentals, DOM manipulation, event handling, form validation, and dynamic UI updates by building an interactive mobile financial services interface.

**Note:** PAYOO is a frontend demonstration project. Its login, PIN verification, and transaction features should not be treated as production-grade banking security or real financial services.
